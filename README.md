# Portfolio — Jerónimo Ahumada Torres

Portfolio profesional orientado a búsquedas de desarrollador .NET Junior. Presenta perfil técnico, proyectos, experiencia y formas de contacto.

## Tecnologías

- Next.js 16 y React 19
- TypeScript
- Tailwind CSS 4
- Vercel

## Desarrollo local

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000) en el navegador.

## Verificación

```bash
npm run lint
npm run build
```

## Estructura principal

- `src/app/page.tsx`: composición y secciones de la página.
- `src/lib/data.ts`: datos personales, habilidades, proyectos y experiencia.
- `src/app/globals.css`: sistema visual y estilos responsive.
- `src/app/components/RevealOnScroll.tsx`: animación progresiva al recorrer el sitio.
